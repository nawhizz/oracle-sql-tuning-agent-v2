# MVP 베타 운용 계획 — Go/No-Go ⑤ 사용자 수용률 측정

PRD §7.2 의 5번째 Go/No-Go 기준(사용자 수용률 70% 이상)은 자동화로 측정할 수 없는 운용 지표이다. 본 문서는 v0.1.0 동기화 직후 시작하는 **베타 운용 절차**를 정의한다.

## 1. 베타 사용자 모집

| 항목 | 기준 |
|------|------|
| 인원 | 5 ~ 10명 |
| 구성 | 주니어 개발자 3 ~ 5, 시니어 개발자 1 ~ 3, DBA 1 |
| 환경 | Oracle 19c 운영 또는 스테이징 환경 접근 권한 보유 |
| 기간 | v0.1.0 동기화 시점 + 4주 |
| 참여 동의 | 수집 정보(피드백 양식)에 대한 사내 보안 검토 완료 후 모집 |

## 2. 운용 절차

### 2.1 시작
1. 베타 안내 메일 발송 — Claude.ai Project 접근 방법, 사용 시나리오, 피드백 양식 링크 포함.
2. 30분 온보딩 세션 — 수집 SQL 복사·실행·붙여넣기 흐름 시연.

### 2.2 사용
- 사용자는 자신의 실제 튜닝 대상 SQL을 가져와 Project 에서 새 대화로 진행.
- 민감 데이터는 사용자 측에서 마스킹 후 입력(가이드 제공).
- 매 세션 종료 시 피드백 양식 작성.

### 2.3 집계
- **주간 집계** — 매주 금요일 오후 5시. 누적 세션 수, 수용률, 부정확 권고 비율, 평균 라운드 수.
- 4주 종료 후 종합 리포트 작성 → `docs/beta_rollout_report_v0.1.0.md`.

## 3. 피드백 양식 (필수 항목)

| # | 질문 | 형식 |
|---|------|------|
| 1 | 튜닝 대상 SQL 카테고리 | 단일/2 테이블/3 테이블/그 외 |
| 2 | 튜닝 결과를 채택했는가? | 그대로 / 약간 수정 / 채택 안 함 |
| 3 | 수집 SQL 중 실행 오류가 발생한 SQL이 있었는가? | 예 / 아니오 + 오류 SQL 본문 |
| 4 | 정보 요청 라운드 수 | 1 / 2 / 3 / 4+ |
| 5 | 부정확 권고가 있었는가? | 예 / 아니오 + 사유 |
| 6 | 권고를 적용한 후의 측정 결과 (있으면) | Buffers·A-Time before/after |
| 7 | 자유 의견 | 텍스트 |

## 4. 성공 지표 (PRD §9 + 본 베타용 정의)

| 지표 | 측정 방법 | 목표치 | Go/No-Go 매핑 |
|------|-----------|--------|----------------|
| 튜닝 결과 수용률 | (그대로 채택 + 약간 수정) / 전체 세션 | ≥ 70% | **⑤** |
| 수집 SQL 실행 성공률 | 오류 없는 수집 SQL 비율 | ≥ 98% | ③ 보강 |
| 평균 정보 요청 라운드 수 | 라운드 수 평균 | ≤ 3 | ② 보강 |
| 부정확 권고 비율 | (부정확 응답 / 전체) | ≤ 5% | 정확성 |
| 평균 SQL 성능 개선율 (적용 시) | (원본 - 튜닝) / 원본 의 중간값 | ≥ 50% | PRD §9 |

## 5. 의사결정

베타 종료 후 다음 중 하나를 선택한다.

- **GO** — 5개 지표 모두 목표 충족 → Stage 2 (자체 웹 UI) 착수. v0.1.0 을 정식 v1.0.0 으로 승격할지는 별도 결정.
- **CONDITIONAL GO** — 1 ~ 2 개 미달이나 원인 명확 → 개선 항목을 `prompts/CHANGELOG.md` 의 v0.2.0 백로그로 이관. 2주 추가 베타 후 재평가.
- **NO GO** — 다수 미달 또는 부정확 권고 비율 10% 초과 → 프롬프트 개선 루프 재진입. v0.2.0 정식 릴리즈 후 베타 재시작.

## 6. 보안·개인정보 운영

- 사용자가 입력한 SQL/데이터는 Claude.ai Project 의 대화 히스토리에 저장된다. 베타 사용자는 다음을 준수한다.
  - 실 운영 데이터 직접 입력 금지. 마스킹 또는 합성 데이터로 변환.
  - 회사 내부 식별자(테이블·컬럼)에 대해서는 사내 보안 정책에 따라 사전 검토.
- 4주 베타 종료 후 Claude.ai Project 의 모든 대화 이력은 별도 보존하지 않는다(필요 시 사용자 본인이 export).
