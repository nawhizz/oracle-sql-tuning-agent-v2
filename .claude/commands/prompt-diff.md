---
description: 직전 커밋 대비 prompts/ 변경 사항을 요약하고 CHANGELOG 초안을 제안한다.
---

다음을 순서대로 수행한다.

1. 변경 범위 확인:
   ```
   git diff HEAD~1 -- prompts/
   ```
2. 변경된 파일 목록과 각 파일의 추가·삭제 라인 수를 표로 요약한다.
3. 각 모듈의 변경을 다음 분류로 정리한다.
   - 새로운 규칙 추가
   - 기존 규칙 수정 (의미 변화)
   - 형식·문구 정리 (의미 동일)
4. 다음 형식으로 `prompts/CHANGELOG.md` 추가 항목 초안을 사용자에게 제시한다.

   ```markdown
   ## v0.x.0 — <yyyy-mm-dd> (<git-short-hash>)
   - <변경 1>
   - <변경 2>
   영향 시나리오: <시나리오 ID 또는 "재검증 필요">
   ```
5. 회귀 테스트 재실행이 필요한지 권고. 의미 변화가 있으면 `/run-tests` 실행을 권한다.

`prompts/` 외 디렉토리의 변경은 본 명령에서 다루지 않는다.
